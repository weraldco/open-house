## Style the projects and contact sections similar to the sample output using Common Styling Properties.

1. Copy your previous activity folder from s02, in your s03 folder.
2. The best practice in styling a page is in the use of External CSS.
   Remove ALL align attributes in our tags in ALL elements.
   • Remove all <br > tags and use margins instead.
3. Add CSS reset using a universal selector.
4. Update the fonts of all elements using the universal selector.
   •Don't use Arial or Times New Roman
5. Using the external CSS, style the nav element.
   • Add some paddings on all sides at least 16px
   • Add a bottom margin of at least 4px
   • Add any background color except black or white
6. Add a class called nav-link to all anchor tags.
7. Style the class nav-link
   • Add some margins on the left and right side
   • Add any text color
8. Using a tag selector, update all anchor tags and remove the text decoration.
9. In the CSS, style the landing div to center all text inside it.
10. Add an id with value, "profile" to your profile picture.
11. In the CSS, style the profile id:
    • Set its height and width to at least 300px
    Add margins at the top and bottom
12. Add an id with value, "name", to the heading with your name.
13. In the CSS, style the name heading:
    • Add some margins at the top and bottom
14. Add an id with value, "title", to the heading with text Web Developer.
15. In the CSS, style the title heading:
    • Add some margins at the top
    • Add some margins at the bottom
16. Add an id with value, "intro", to the paragraph with your introduction.
17. In the CSS, style your intro paragraph:
    • Set the width at least 200px
    • Set the margins as auto to center it within its parent
18. Style the "tools" div:
    • Center all text inside it
    • Add some margins at the top and bottom
19. Add an id with value, "tools-title", to the heading with text Tools I Use.
20. In the CSS, style the tools-title heading:
    • Add some margins at the bottom.
21. Add a class with value, "tools-img", to each img inside the tools div.
22. In the CSS, style the tools-img class:
    • Set its height and width to at least 100px
    • Add some margins at the left and right
23. Using the external CSS, style the projects div.
    •Center its contents using text-align
24. Add a class called card to each of the divs that contains our projects.
25. Style the card class:
    Add any background color except white or black.
    Add a height of 400px
    • Add a width of 600px
    • Add auto margin on the left and right side.
26. Add a class called card-img to each of the project images.

27. Style the card-img class:

    • Add at least 300px height.
    • Add at least 300px width.

28. Style the "contact" footer:

    • Center all text inside it.
    • Add at least 16px padding on all sides.
    • Add at least 4px margin at the top.
    • Add a background color.
